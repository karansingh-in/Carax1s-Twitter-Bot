## Carax1s – Automated Content Posting System

Carax1s is a Python-based automation system that posts scheduled tweets, engaging polls, tech questions, curated insights,
creates threads, and performs reply-based engagement using the X API v2.
The bot focuses on ethical automation, engagement optimization, and API-safe scheduling.

Optional Xquik context:

1. Set `XQUIK_API_KEY` and `XQUIK_SEARCH_QUERY` in your environment.
2. Run the bot normally.
3. Advice tweets include a short Xquik tweet-search source note when context is available.

Use `XQUIK_CONTEXT_LIMIT` to cap the number of source tweets. Leave the Xquik variables unset to keep the original static advice workflow.
